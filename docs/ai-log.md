# Журнал взаємодії з AI

Інструмент: GitHub Copilot Chat (VS Code), режим Agent
Автор: Кокоруз Соломія, КІ-405, варіант 5 (Java + Maven + JUnit)

## Запис 1. Manifest агента

**Запит:**
Створити файл `.github/agents/build-engineer.agent.md` з manifest агента build-engineer для Java/Maven проєкту Hello World: front matter, роль, область відповідальності, правила роботи з файлами, заборонені дії, порядок роботи, критерії успішного завершення.

**Відповідь Copilot:**
Створено manifest з усіма розділами.

**Проблеми, які я знайшла:**
1. У розділі «Порядок роботи» `init` був шостим кроком після `check`, хоча це оркестратор, який сам викликає решту команд.
2. `create-project` не був прив'язаний до skill `project-scaffold`.
3. У front matter не було поля `tools`.

**Прийняте рішення:**
Не правити файл вручну, а попросити Copilot виправити.

## Запис 2. Виправлення manifest

**Запит:**
Додати поле `tools` у front matter, переписати розділ 5 так, щоб кожна command була прив'язана до свого skill, а `init` був оркестратором, що зупиняється при першій помилці.

**Результат:**
Manifest виправлено: додано `tools`, розділ 5 переписано правильно.

**Перевірка:**
Файл прочитано. Перший рядок `---`, обгортки ``` у файлі немає.

## Запис 3. Skills
**Запит:** створити три skills (project-scaffold, build-and-test, github-actions) з розділами: призначення, входи, виходи, кроки, перевірки, типова помилка.
**Результат:** створено три `SKILL.md`, Copilot сам перевірив front matter і розділи.

## Запис 4. Prompts (commands)
**Запит:** створити шість prompts: git-init, create-project, create-build, create-actions, check, init.
**Проблема:** Copilot виявив суперечність у моїх вимогах: `check` не має змінювати файли, але Maven створює `target/`.
**Рішення:** дозволити Maven створювати `target/` (тимчасовий каталог поза Git), а вихідні та конфігураційні файли `check` не змінює.
**Результат:** створено шість prompt-файлів.

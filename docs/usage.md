# Використання проєкту та AI-агента

Усі команди агента запускай у VS Code Copilot Chat у режимі Agent після вибору `build-engineer`. Якщо проміжні файли вже створені, можна запускати відповідну окрему команду замість повного `/init-project`.

## Запуск команд агента

Повне послідовне налаштування, включно з перевірками передумов:

```text
/init-project
```

Окремі етапи:

```text
/git-init
/create-project
/create-build
/create-actions
/check
```

Запускай етапи за порядком, якщо виконуєш їх окремо. `/check` лише перевіряє файли та конфігурацію, але може створювати або оновлювати build-артефакти в `target/`, оскільки запускає Maven-перевірки.

## Локальна перевірка

Виконуй команди з кореня repository:

- Windows: `ci.bat`
- Linux/macOS: `./ci.sh`

CI-скрипти запускають Maven build і тести, а також перевіряють, що створився `target/hello.jar`. Перед виконанням мають бути встановлені JDK 17 і Maven та доступна команда `mvn`.

## Запуск `hello.jar`

Після успішної збірки з кореня repository виконай:

```sh
java -jar target/hello.jar
```

Застосунок має вивести `Hello, World!`.

## Перевірка, що `target/` не потрапляє в Git

Переконайся, що `target/` зазначено в `.gitignore`, а створений JAR ігнорується:

```sh
git check-ignore -v target/hello.jar
```

Команда має вивести правило `.gitignore`, яке ігнорує цей шлях. Перевір, чи є відстежувані Git-файли в `target/`:

```sh
git ls-files -- target/
```

Очікуваний результат — порожній вивід. Якщо команда показує файли, вони вже відстежуються Git; правило `.gitignore` саме по собі не припиняє відстеження наявних файлів.

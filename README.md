# apks-lab1-hello-java

## Відомості про лабораторну роботу

- **ПІП:** Кокоруз Соломія
- **Група:** КІ-405
- **Варіант:** 5 (Java, Maven, JUnit 5)

## Опис проєкту

Проєкт демонструє використання AI-агента build-engineer для створення та перевірки кросплатформного Java Hello World застосунку. Агент налаштовує Maven-збірку, JUnit 5 тест `BasicAddition`, CI-скрипти та GitHub Actions workflow.

## Запуск AI-агента

1. Відкрий репозиторій у VS Code.
2. Відкрий Copilot Chat у режимі Agent.
3. Обери агента `build-engineer`.
4. Виконай команду `/init-project`.

Оркестратор перевіряє Java, Maven і Git, а потім послідовно запускає налаштування проєкту, збірки, CI та фінальну перевірку.

## Запуск зібраного проєкту

З кореня репозиторію виконай відповідний CI-скрипт:

- Windows: `ci.bat`
- Linux/macOS: `./ci.sh`

Скрипт запускає перевірки Maven і створює виконуваний `target/hello.jar`. Запусти застосунок командою:

```sh
java -jar target/hello.jar
```
